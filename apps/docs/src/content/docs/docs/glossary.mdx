---
title: 用詞
description: 手冊裡常出現的詞，每個用一兩句話說明。
---

這本手冊盡量用平常的話來寫，但有些詞會一直出現。這裡用一兩句話說明它們的意思。

## token（設計數值）

一個有名字的設計數值，例如「主色＝深藍 #1B2D58」。大家都用名字來指它，要改顏色時只改一個地方，所有用到它的地方都會跟著變。

## 基礎

最底層的規則：顏色、文字大小、間距等。元件、範本和網站主題都建立在基礎上，見[色彩](/foundations/colors/)和[字體](/foundations/typography/)。

## 語意色

依「用途」命名的顏色，例如「主色」「文字」「背景」「錯誤提示」。元件只用語意色，所以換網站主題或色彩模式時，只要換語意色對應到的實際顏色。

## 元件 token

只給某一個元件用的設計數值，例如「按鈕的圓角」。它通常指向一個語意色或基礎數值，需要的時候可以只調整這個元件。

## 網站主題

「哪一個網站」的外觀，例如慈濟入口網、慈濟環保網。網站主題只決定語意色在這個網站用什麼顏色；元件和版面所有網站都一樣。見[網站主題](/themes/)。

## 色彩模式

淺色或深色。每個網站主題都有淺色和深色兩組顏色，讀者可以自己切換。色彩模式不是網站主題，見[色彩模式](/foundations/theming/)。

## 變體

同一個元件的不同樣子，例如按鈕有實心、外框、淡色等樣子。變體所有網站都能用，跟是哪個網站無關。

## 版本

當一個元件要整個換掉，而且新舊不能直接互換時，就出新版本。版本只有 v1、v2 這樣的編號，所有網站一起升級，不會每個網站各一份。
