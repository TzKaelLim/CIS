---

這本手冊盡量用平常的話來寫，但有些詞會一直出現。這裡用一兩句話說明它們的意思。

## UIKit

慈濟所有網站共用的一整套設計規則和現成元件，也就是這本手冊在講的東西。

## token（設計數值）

一個有名字的設計數值，例如「主色＝深藍 #1B2D58」。大家都用名字來指它，要改顏色時只改一個地方，所有用到它的地方都會跟著變。

## 基礎

最底層的規則：顏色、文字大小、間距等。元件、範本和網站主題都建立在基礎上，見[色彩](/foundations/colors/)和[字體](/foundations/typography/)。

## 語意色

依「用途」命名的顏色，例如「主色」「文字」「背景」「錯誤提示」。元件只用語意色，所以換網站主題或色彩模式時，只要換語意色對應到的實際顏色。

## 元件 token

只給某一個元件用的設計數值，例如「按鈕的圓角」。它通常指向一個語意色或基礎數值，需要的時候可以只調整這個元件。

## 網站主題

「哪一個網站」的外觀，例如慈濟入口網、慈濟環保網。每個網站有一個自己的網站主題，決定每個語意色在這個網站用哪個顏色；必要時也可以調整個別元件 token。元件和版面所有網站都一樣，不會因網站而不同。見[網站主題](/themes/)。

## 色彩模式

淺色或深色，由讀者自己切換。每個網站主題都附有淺色和深色兩組顏色。色彩模式不是網站主題：網站主題是「哪個網站」，色彩模式是「淺色還是深色」，兩者可以自由搭配。見[色彩模式](/foundations/theming/)。

## 變體

同一個元件的不同樣子，例如按鈕有實心、外框、淡底三種。變體所有網站都能用，跟是哪個網站無關。

## 版本

元件整個重新設計、而且新舊不能直接互換時，才出新版本。版本只用整數，例如 v1、v2，沒有 v1.1 這種小數字；小幅調整不會出新版本。所有網站一起升級，不會每個網站各一份。

## 範本

用元件組好的整頁版面，例如入口首頁、文章列表。做新網頁時照著排，再換上自己的內容。見[範本](/templates/)。

## 修改申請（MR）

把修改交給核可人看的申請。工程師叫它 MR（merge request）。見[如何參與修改](/docs/contributing/)。

## Storybook

工程師逐一檢查元件各種狀態的工具網站。它只在正式上線的手冊才開得了，見[開始使用](/docs/#給工程師)。
