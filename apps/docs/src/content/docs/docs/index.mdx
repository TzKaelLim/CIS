**慈濟 CIS UIKit 是一套給所有慈濟網站共用的設計規則和元件。** 顏色、文字大小、按鈕、卡片、整頁的排法都只做一次，每個網站拿來用就好；每個網站再換上自己的「網站主題」，就有自己的顏色。

## 這套 UIKit 解決什麼問題

慈濟有很多網站，以前每個網站各自設計按鈕、卡片和顏色，同一件事常常有好幾種做法，改一次也要每個網站各改一次。

UIKit 把這些共通的部分收在一起：

- **一套規則**：顏色、文字、間距都有名字和固定的值，大家講同一套話。
- **一套元件**：按鈕、搜尋列、文章卡片、頁尾…每一個都只有一份，所有網站一起用。
- **每個網站一個網站主題**：只換顏色等外觀數值，元件和版面都不用重做。

## 頁首的兩個選單

- **網站主題**：選一個網站（例如慈濟入口網、慈濟環保網），手冊裡所有元件和範本的顏色就換成那個網站的樣子。
- **色彩模式**：淺色或深色。每個網站主題都有淺色和深色，兩個選單可以自由搭配。

手冊本身（頁首、側欄、文字）的顏色不會跟著變，只有元件和範本會變。你的選擇會被記住，下次打開還是同一個。

## 給工程師

元件的每一種狀態、屬性和程式碼範例都在 **Storybook**（工程師用來逐一檢查元件的工具網站）：

<StorybookLink label="開啟 Storybook" />

Storybook 是工程師逐一檢查元件各種狀態的工具網站，放在手冊同一個網址底下的 `/storybook/`。它只在正式上線的手冊才開得了；在自己的電腦上預覽手冊時，按鈕會顯示找不到頁面。每個元件頁的「給工程師」一段也有安裝方式和 API 說明。
