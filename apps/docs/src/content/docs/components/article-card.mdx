`<tc-article-card>` 是文稿型內容卡片，以 `orientation`（vertical／horizontal）、`featured`（焦點放大）與插槽組合涵蓋焦點文稿、一般文稿、互動式文稿、公告、影片、志工早會與週報等版式。提供 media／badge／headline／excerpt／meta／actions 插槽，支援影片播放遮罩（`video`）、可互動（`interactive`）與整張卡片連結（`href`，stretched link）模式。下方為**可互動的真實元件**（圖片為 Lorem Picsum 假圖）：

## 連結模式與動作區（Stretched Link + actions）

設定 `href` 後整張卡片透過覆蓋層 `<a>` 變成連結；`actions` 內的控件（如讚／分享）仍可獨立點擊，不會被連結攔截：

## 無障礙（Accessibility）

- `href` 模式以原生 `<a>` 為焦點與互動目標，支援鍵盤 Enter。
- `interactive`（無 `href`）模式下，host 取得 `tabindex="0"` 與 `role="button"`，並以 Enter／Space 觸發 `tc-card-click`。
- `actions` 內的可聚焦控件不會被巢狀於連結中，可獨立鍵盤操作。
- 影片播放鈕為純視覺提示（`aria-hidden`），實際播放語意由媒體或連結目標承載。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
