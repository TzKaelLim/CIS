## 用法

文章卡片是新聞、文章列表裡的一則：一張圖片，加上分類、標題、兩三行摘要和日期，讀者看一眼就知道要不要點進去讀。同一個元件可以排成圖片在上的直式（上方第一張）或圖片在左的橫式（上方第二張），也可以放大成凸顯最重要一則的焦點版式，或在圖片上疊一個播放鈕表示影片（兩種的樣子見下方「給工程師」的範例）。不需要分類、摘要和日期的一般項目（例如專案、募款項目）用「卡片」；以封面為主的書籍用「書籍卡片」；側欄裡只有標題和日期的短清單用「清單面板」。

## 組成

| 部位       | 說明                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------- |
| 容器       | 卡片的底色、圓角和淡淡的陰影，顏色跟著網站主題。                                         |
| 圖片       | 可省略。直式時放在最上方；橫式時放在左邊，約佔卡片寬度的四成。                           |
| 播放鈕     | 只有影片卡片才有：疊在圖片中央的圓形播放鈕。它只是給眼睛看的提示，螢幕閱讀器不會唸出來。 |
| 分類標籤   | 可省略。標題上方的小標籤，例如「慈善」「影片」。                                         |
| 標題       | 品牌主色的粗體字，最多顯示兩行，超過的部分會被截掉並顯示「…」。焦點版式的標題比較大。    |
| 摘要       | 可省略。一般文字色，最多顯示三行，超過的部分會被截掉。                                   |
| 日期與來源 | 可省略。最下方的小字，用比較淡的次要文字色。                                             |
| 動作區     | 可省略。例如「讚」「分享」的小按鈕；整張卡片可以點時，這些按鈕仍然可以單獨按。           |
| 焦點框     | 用鍵盤選到可點的卡片時出現的外框，讓不用滑鼠的人知道目前在哪裡。                         |

### 無障礙（Accessibility）

- `href` 模式以原生 `<a>` 為焦點與互動目標，支援鍵盤 Enter。
- `interactive`（無 `href`）模式下，host 取得 `tabindex="0"` 與 `role="button"`，並以 Enter／Space 觸發 `tc-card-click`。
- `actions` 內的可聚焦控件不會被巢狀於連結中，可獨立鍵盤操作。
- 影片播放鈕為純視覺提示（`aria-hidden`），實際播放語意由媒體或連結目標承載。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
