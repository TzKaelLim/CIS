## 用法

書籍卡片以封面為主：封面圖佔卡片的大部分，下面只有書名、一行副標和「更多」這類連結，適合書籍、出版品和「每日一叮嚀」這類以一張圖為主角的內容。封面可以是直式（3:4，上方前兩張）或方形（1:1，上方第三張）。圖片不是主角、需要較長說明或按鈕的項目用「卡片」；新聞、文章列表用「文章卡片」。

## 組成

| 部位     | 說明                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 容器     | 卡片的底色、圓角和淡淡的陰影，顏色跟著網站主題。                                         |
| 封面     | 卡片上方的大圖，依設定裁成直式（3:4）或方形（1:1）；比例不合的圖片，超出的部分會被裁掉。 |
| 標題     | 書名，用品牌主色的粗體字，最多顯示兩行，超過的部分會被截掉並顯示「…」。                  |
| 副標     | 可省略。標題下方的淡色小字，只顯示一行，超過的部分會被截掉。                             |
| 動作區   | 可省略。最下方的連結或按鈕，例如「更多」；整張卡片可以點時，這裡仍然可以單獨按。         |
| 整張可點 | 可省略。整張卡片連到另一頁時，滑過卡片陰影會變深、標題變色。注意：這個舊元件給螢幕閱讀器的連結名稱是英文的「book card link」，不是書名；正式網站要用之前，請工程處理。 |
| 焦點框   | 用鍵盤選到可點的卡片時出現的外框，讓不用滑鼠的人知道目前在哪裡。                         |

### 寬度（width）

`width` 接受任何 CSS 長度（如 `240px`、`100%`），等同設定 `--tc-book-card-width`。

### 無障礙（Accessibility）

- `href` 模式以原生 `<a>` 為焦點與互動目標，支援鍵盤 Enter。
- `interactive`（無 `href`）模式下，host 取得 `tabindex="0"` 與 `role="button"`，並以 Enter／Space 觸發 `tc-book-card-click`。
- `footer` 內的可以用鍵盤選到的控制項不會被巢狀於連結中，可獨立鍵盤操作。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
