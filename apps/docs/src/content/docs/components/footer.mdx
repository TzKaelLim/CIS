`<tc-footer>` 是網站頁尾容器：上方彩色內容區（品牌資訊、社群連結、一組 `<tc-footer-column>` 連結群組、回到頂部）加上底部版權列。連結群組以 CSS grid `auto-fit`／`minmax` 排列（桌機約 4-6 欄、平板 2 欄、行動 1 欄）；在 `<=768px` 時每個 `<tc-footer-column>` 變為可收合的手風琴。提供 `light`（淺色）與 `brand`（深色品牌）兩種變體。下方為**可互動的真實元件**（社群圖示為 Lorem Picsum 假圖）：

## 用法

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-footer copyright="Copyright © 2020 Tzu Chi Foundation.">
  <a slot="social" href="https://facebook.com" aria-label="Facebook">FB</a>
  <div slot="brand">花蓮本會 · 03 856 6779</div>

  <tc-footer-column label="公益慈善">
    <tc-link variant="subtle" href="/relief">國際賑災</tc-link>
    <tc-link variant="subtle" href="/volunteer">全球志工服務</tc-link>
  </tc-footer-column>
  <tc-footer-column label="醫療志業">
    <tc-link variant="subtle" href="/hospital">花蓮慈濟醫院</tc-link>
  </tc-footer-column>
</tc-footer>
```

### React

```tsx
import { TcFooter, TcFooterColumn } from '@tzuchi/react';

<TcFooter variant="light" copyright="Copyright © 2020 Tzu Chi Foundation.">
  <div slot="brand">花蓮本會</div>
  <TcFooterColumn label="公益慈善">
    <a href="/relief">國際賑災</a>
  </TcFooterColumn>
</TcFooter>;
```

## 無障礙（Accessibility）

- 頁尾容器為 `<footer role="contentinfo">`。
- 每個 `<tc-footer-column>` 為 `role="group"`：桌機標題以 `<h3>` 靜態呈現、連結恆顯示；行動裝置（`<=768px`）標題改為按鈕，帶 `aria-expanded`／`aria-controls`，連結容器為 `role="region"` 並以 `aria-labelledby` 連結標題。
- 切換手風琴時 `<tc-footer-column>` 派發 `tc-toggle`，`detail.open` 為新狀態。
- 內建「回到頂部」按鈕帶 `aria-label`，點擊派發 `tc-back-to-top` 並平滑捲動至頁首；亦可改用 `back-to-top` 插槽提供自訂控件。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
