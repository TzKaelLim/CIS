## 用法

頁尾放在每一頁的最下方，收網站的聯絡資訊、社群連結、分類連結和版權聲明，右上角還有內建的「回到頂部」按鈕。連結依群組排列：寬畫面上排成多欄，平板排成兩欄，手機排成一欄，而且手機上可以點群組的標題收起或展開。網站最重要的幾個區域放在「導覽列」；頁尾放比較完整、但比較少用到的連結。元件另有一個品牌底色（brand）變體，但目前在網站上看起來和預設一樣（待工程修正），請先用預設。

## 組成

| 部位       | 說明                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| 上方內容區 | 頁尾的主要區塊，用淡淡的底色和頁面內容分開。底色和文字色跟著網站主題和色彩模式變。                       |
| 社群連結   | 可省略。左上角一排社群網站的小圖示連結，由網站提供。                                                     |
| 回到頂部   | 右上角內建的按鈕，按下會捲回頁面最上方。需要不同的樣子時，可以換成網站自己的按鈕。                       |
| 品牌區     | 可省略。網站或單位的名稱、地址、電話，也可以放一個按鈕，例如「聯絡我們」。寬畫面在左邊，窄畫面在最上面。 |
| 連結群組   | 一組有標題的連結，例如「公益慈善」。手機上標題變成可以點的按鈕，點了收起或展開這一組連結，預設是展開。   |
| 版權列     | 最下面一條，用網站主題的主色當底，文字用和底色對比的顏色，寫版權聲明。沒有版權文字時就不顯示。                         |
| 焦點框     | 用鍵盤選到按鈕或連結時出現的外框，讓不用滑鼠的人知道目前在哪裡。顏色跟著網站主題。                       |

### 無障礙（Accessibility）

- 頁尾容器為 `<footer role="contentinfo">`。
- 每個 `<tc-footer-column>` 為 `role="group"`：桌機標題以 `<h3>` 靜態呈現、連結恆顯示；行動裝置（`<=768px`）標題改為按鈕，帶 `aria-expanded`／`aria-controls`，連結容器為 `role="region"` 並以 `aria-labelledby` 連結標題。
- 切換手風琴時 `<tc-footer-column>` 發出 `tc-toggle`，`detail.open` 為新狀態。
- 內建「回到頂部」按鈕帶 `aria-label`，點擊發出 `tc-back-to-top` 並平滑捲動至頁首；亦可改用 `back-to-top` 插槽提供自訂控制項。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
