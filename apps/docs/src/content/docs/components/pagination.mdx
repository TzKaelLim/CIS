## 用法

分頁用在同一份列表分成很多頁的時候，例如新聞列表、搜尋結果，讓讀者切換到第幾頁，或往前、往後一頁。頁數多時，中間的頁碼會收成「…」，第一頁、最後一頁和目前頁碼的前後一頁一直看得到（見上方的預覽）。分頁元件只有這一排按鈕，換頁之後要顯示哪些內容，由網站自己處理。只有兩三組不同的內容要切換時，請改用「頁籤」。

## 組成

| 部位       | 說明                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 上一頁按鈕 | 左邊的箭頭。在第一頁時變淡，不能按。螢幕閱讀器唸作「上一頁」。                     |
| 頁碼       | 每一頁一個按鈕，螢幕閱讀器唸作「第 3 頁」這樣的完整說法。                          |
| 目前頁碼   | 讀者現在所在的那一頁，用網站主題的主色當底，文字用和底色對比的顏色。                            |
| 省略號     | 頁數多時代替中間收起來的頁碼，只是提示，不能按。                                   |
| 下一頁按鈕 | 右邊的箭頭。在最後一頁時變淡，不能按。螢幕閱讀器唸作「下一頁」。                   |
| 焦點框     | 用鍵盤選到任一個按鈕時出現的外框，讓不用滑鼠的人知道目前在哪裡。顏色跟著網站主題。 |

## 給工程師

以下是給工程師的安裝與 API 說明，美編（設計）、網站的編輯和廠商可以略過。

<StorybookNote tag="tc-pagination" />

`<tc-pagination>` 提供分頁導覽：上一頁、頁碼、下一頁。目前頁碼以品牌主色凸顯並標記 `aria-current="page"`，頁數過多時以省略號收合。下方為**可互動的真實元件**：

<Demo>
  <tc-pagination total="8" page="1"></tc-pagination>
</Demo>

頁數過多時，會依 `sibling-count`（目前頁碼兩側的頁數）與首／末頁收合中間範圍：

<Demo>
  <tc-pagination total="20" page="10"></tc-pagination>
  <tc-pagination total="20" page="10" sibling-count="2"></tc-pagination>
</Demo>

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-pagination total="8" page="1"></tc-pagination>
<script>
  document.querySelector('tc-pagination').addEventListener('tc-page-change', (e) => {
    console.log('目前頁碼：', e.detail.page);
  });
</script>
```

### React

```tsx
import { TcPagination } from '@tzuchi/react';

<TcPagination total={8} page={page} onTcPageChange={(e) => setPage(e.detail.page)} />;
```

### 事件

| 事件名稱         | detail            | 說明                       |
| ---------------- | ----------------- | -------------------------- |
| `tc-page-change` | `{ page: number }` | 頁碼改變時發出（會冒泡）。 |

### 無障礙（Accessibility）

- 外層為 `<nav aria-label>`，頁碼與上一頁／下一頁皆為原生 `<button>`，支援鍵盤 Enter / Space。
- 目前頁碼標記 `aria-current="page"`，每個頁碼具有 `aria-label`（如「第 3 頁」）。
- 第一頁時停用「上一頁」、最後一頁時停用「下一頁」（透過原生 `disabled`，非 `pointer-events:none`）。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
