## 用法

頁籤讓讀者在同一個地方切換幾組同一層級的內容，例如「總覽」「最新消息」，不用離開這一頁，一次只看一組。它有兩種版面：寬版（web，預設）的頁籤依文字長短排成一列；窄版（mobile）的頁籤平分整列的寬度，適合手機上的少數幾個頁籤。頁籤元件只有上面這一排頁籤，下面要換成哪一組內容，由網站自己處理。要前往另一個頁面請用「導覽列」或「連結」；同一份列表分成很多頁時請用「分頁」；依分類篩選同一份列表（例如只看「慈善」的消息）請用「膠囊標籤」，頁籤用在切換不同的內容區塊。

## 組成

| 部位     | 說明                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 頁籤列   | 一排頁籤，下方有一條分隔線。寬版依文字長短排列；窄版每個頁籤一樣寬，撐滿整列。                         |
| 頁籤文字 | 必填。每個頁籤的名稱，只排一行，不會換行。螢幕閱讀器會唸出這段文字，也會說出它是不是目前選中的頁籤。   |
| 前置圖示 | 可省略。放在文字前面的小圖示，用來補充文字，不能取代文字。                                             |
| 選取底線 | 目前選中的頁籤，文字變粗、改用主題的主色，下方加一條主色底線。                                     |
| 停用狀態 | 暫時不能選的頁籤會變淡，點了不會切換。                                                                 |
| 焦點框   | 用鍵盤選到頁籤時出現的外框。用左右方向鍵切換頁籤，Home、End 鍵跳到第一個、最後一個。顏色跟著主題。 |

以下是給工程師的安裝與 API 說明，美編（設計）、網站的編輯和致遠（廠商）可以略過。

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-tabs value="overview">
  <tc-tab value="overview">總覽</tc-tab>
  <tc-tab value="news">最新消息</tc-tab>
</tc-tabs>
```

切換時會發出 `tc-tab-change` 事件（`composed`、`bubbles`），`detail.value` 為新選取的值：

```js
document.querySelector('tc-tabs').addEventListener('tc-tab-change', (e) => {
  console.log(e.detail.value);
});
```

### React

```tsx
import { TcTabs, TcTab } from '@tzuchi/react';

<TcTabs value="overview" onTcTabChange={(e) => setTab(e.detail.value)}>
  <TcTab value="overview">總覽</TcTab>
  <TcTab value="news">最新消息</TcTab>
</TcTabs>;
```

### 無障礙（Accessibility）

- `<tc-tabs>` 為 `role="tablist"`，`<tc-tab>` 為 `role="tab"`。
- 鍵盤瀏覽：方向鍵切換頁籤、Home / End 跳至首末，採 roving tabindex（僅選取項在 Tab 順序中）。
- `disabled` 以 `aria-disabled` 表示，仍可被方向鍵掠過但不會被選取（非 `pointer-events:none`）。
- 選取狀態以 `aria-selected` 反映，選取頁籤顯示品牌主色底線指示。
