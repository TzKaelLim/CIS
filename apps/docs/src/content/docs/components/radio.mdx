`<tc-radio>` 是 24×24 的單選圓鈕，提供外圈 ring 與選取時填滿的內點，並支援 form-associated 表單提交。同 `name` 的 `<tc-radio>` 互斥，僅能選取一個。下方為**可互動的真實元件**：

<Demo>
  <div style="display:flex; flex-direction:column; gap:.5rem;">
    <tc-radio name="demo" value="a" checked>選項一</tc-radio>
    <tc-radio name="demo" value="b">選項二</tc-radio>
    <tc-radio name="demo" value="c">選項三</tc-radio>
    <tc-radio name="demo" value="d" disabled>停用選項</tc-radio>
  </div>
</Demo>

## 用法

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-radio name="color" value="red">紅</tc-radio>
<tc-radio name="color" value="blue">藍</tc-radio>
```

### React

```tsx
import { TcRadio } from '@tzuchi/react';

<TcRadio name="color" value="red" onTcChange={handleChange}>紅</TcRadio>;
```

## 群組與表單

同名的 `<tc-radio>` 互斥，選取後其它選項自動取消。`tc-radio` 透過 Form-Associated Custom Elements（ElementInternals）以 `name` / `value` 參與所屬 `<form>` 提交；未選取時不貢獻任何值。加上 `required` 時，群組未選取即為無效。

<Demo>
  <form
    onsubmit="event.preventDefault(); this.querySelector('output').textContent='✅ ' + (new FormData(this).get('size') ?? '未選取');"
    style="display:flex; flex-direction:column; gap:.5rem; align-items:flex-start;"
  >
    <tc-radio name="size" value="s" required>小</tc-radio>
    <tc-radio name="size" value="m">中</tc-radio>
    <tc-radio name="size" value="l">大</tc-radio>
    <button type="submit">提交</button>
    <output></output>
  </form>
</Demo>

## 無障礙（Accessibility）

- `role="radio"` 並同步 `aria-checked` / `aria-disabled`。
- 鍵盤 Space / Enter 選取；方向鍵在同名群組內移動並選取。
- Roving tabindex：群組內僅選取項（或第一個可用項）進入 Tab 順序。
- 焦點環使用 `--tc-focus-ring-*` token。
- `disabled` 透過停用內部原生控件實作（非 `pointer-events:none`），且不可聚焦。
