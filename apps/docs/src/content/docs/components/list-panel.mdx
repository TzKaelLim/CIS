`<tc-list-panel>` 是標題面板：上方為彩色標題列（`brand` 變體為品牌主色底、白字），下方為由預設插槽提供的垂直清單，項目間自動加上細分隔線。標題以 `label` 屬性設定，或用 `header` 插槽覆寫。用 `width` 屬性控制寬度（CSS 長度）。下方為**可互動的真實元件**（圖片為 Lorem Picsum 假圖）：

## 變體（variant）

`brand`（預設）為品牌主色標題列、白字；`plain` 為淡色標題列、內文色標題，適合次要區塊：

<Demo>
  <tc-list-panel variant="plain" label="相關連結" width="360px">
    <article>
      <h3 style="margin:0;font-weight:700;color:#1b2d58">慈濟全球資訊網</h3>
    </article>
    <article>
      <h3 style="margin:0;font-weight:700;color:#1b2d58">慈濟月刊</h3>
    </article>
  </tc-list-panel>
</Demo>

## 無障礙（Accessibility）

- 標題列以 `<h2>` 呈現，建立頁面標題層級；使用 `header` 插槽時請放入適當的標題標籤。
- 清單項目為使用者提供的內容，建議用語意化標籤（如 `<article>`）並維持標題層級。
- 分隔線僅為視覺輔助，不影響朗讀順序。
