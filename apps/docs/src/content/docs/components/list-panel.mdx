## 用法

清單面板是一塊有標題列的直式清單：上面一條彩色的標題列說明這一組是什麼，下面一列一列排出項目，項目之間自動加上細分隔線，常放在首頁側欄，例如「最新消息」。重要的區塊用品牌主色的標題列（上方第一個），次要的區塊例如「相關連結」用淡色的標題列（上方第二個）。每一則都需要圖片和摘要時，請改用「文章卡片」；要讓讀者並排挑選的項目用「卡片」。

## 組成

| 部位     | 說明                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 標題列   | 面板最上方的一條。品牌主色底配白字（brand），或淡色底配一般文字色（plain）。螢幕閱讀器會把它當成這一區的標題。需要圖示時可以換成自訂的標題。 |
| 清單項目 | 標題列下方的一列一列內容，例如標題加日期。每一則是一列，內容由網站自己放。                                                                   |
| 分隔線   | 項目之間的細線，自動加上，不必自己畫。                                                                                                       |
| 外框     | 整個面板的細外框和圓角，顏色跟著網站主題。                                                                                                   |

### 變體（variant）

`brand`（預設）為品牌主色標題列、白字；`plain` 為淡色標題列、內文色標題，適合次要區塊：

### 無障礙（Accessibility）

- 標題列以 `<h2>` 呈現，建立頁面標題層級；使用 `header` 插槽時請放入適當的標題標籤。
- 清單項目為使用者提供的內容，建議用語意化標籤（如 `<article>`）並維持標題層級。
- 分隔線僅為視覺輔助，不影響朗讀順序。
