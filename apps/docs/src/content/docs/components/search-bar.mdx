`<tc-search-bar>` 是外框式（outlined）搜尋列，採用白色底、`radius.md` 圓角與 focus-within 焦點環，視覺與 `<tc-input>` 一致。版面為 `[可選分類選擇器 | 文字輸入框 | 搜尋鈕]`，搜尋鈕使用內嵌的 `search` 圖示。下方為**可互動的真實元件**：

<Demo>
  <tc-search-bar placeholder="搜尋"></tc-search-bar>
</Demo>

## 用法

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-search-bar name="q" placeholder="搜尋"></tc-search-bar>
```

### React

```tsx
import { TcSearchBar } from '@tzuchi/react';

<TcSearchBar
  placeholder="搜尋"
  onTcSearch={(e) => runSearch(e.detail.value, e.detail.category)}
/>;
```

## 含分類選擇器

加上 `with-category` 會在前端顯示分類選擇器，選項以 `categories`（物件陣列 property 或 JSON 字串屬性）提供。切換分類會派發 `tc-category-change`：

<Demo>
  <tc-search-bar
    with-category
    category="book"
    categories='[{"value":"all","label":"全部"},{"value":"book","label":"跨書搜尋"},{"value":"article","label":"文章"}]'
  ></tc-search-bar>
</Demo>

## 事件

- 輸入時派發 `tc-input`，`detail: { value }`。
- 按下 `Enter` 或點擊搜尋鈕派發 `tc-search`，`detail: { value, category }`。
- 切換分類派發 `tc-category-change`，`detail: { category }`。

所有事件皆 `composed` 且 `bubbles`。

## 無障礙（Accessibility）

- 外框為 `<form role="search">`，組成自己的提交流程（非 form-associated）。
- 文字輸入框以 `aria-label`（預設取 `placeholder`）提供無障礙名稱。
- 搜尋鈕 `aria-label="搜尋"`，分類選擇器 `aria-label="搜尋分類"`。
- `:focus-within` 焦點環使用 `border.focus` 與柔光環，內部控制項 `:focus-visible` 使用 `--tc-focus-ring-*` token。
- `disabled` 會停用內部所有原生控制項（非 `pointer-events:none`）。
