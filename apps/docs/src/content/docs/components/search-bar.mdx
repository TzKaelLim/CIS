## 用法

搜尋列讓讀者輸入關鍵字，搜尋網站的內容，通常放在頁首或搜尋結果頁的上方。右邊固定有一個放大鏡按鈕，按下它或按 Enter 就開始搜尋；需要讓讀者先選搜尋範圍時，可以在左邊加上分類選單，例如「全部」「書籍」「文章」。如果是表單裡要填的一個欄位，例如姓名或電子郵件，請改用「輸入框」。

## 組成

| 部位     | 說明                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 外框     | 有圓角和框線的一整條。滑鼠移上去或選到時框線變色；選到時外面還多一圈柔光。                             |
| 分類選單 | 可省略。最左邊的選單，讓讀者先選搜尋範圍。它的寬度有上限，名稱太長會被截掉。                           |
| 輸入區   | 讀者打字的地方。框內的提示文字同時是螢幕閱讀器唸出的名稱，沒有寫時是「搜尋」。                         |
| 搜尋鈕   | 最右邊的放大鏡按鈕，按下去開始搜尋；螢幕閱讀器會唸「搜尋」。                                           |
| 停用狀態 | 整條變淡，不能輸入、不能選分類，也不能按搜尋。                                                         |

## 給工程師

以下是給工程師的安裝與 API 說明，美編（設計）、網站的編輯和廠商可以略過。

<StorybookNote tag="tc-search-bar" />

`<tc-search-bar>` 是外框式（outlined）搜尋列，採用白色底、`radius.md` 圓角與 focus-within 焦點環，視覺與 `<tc-input>` 一致。版面為 `[可選分類選擇器 | 文字輸入框 | 搜尋鈕]`，搜尋鈕使用內嵌的 `search` 圖示。下方為**可互動的真實元件**：

<Demo>
  <tc-search-bar placeholder="搜尋"></tc-search-bar>
</Demo>

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-search-bar name="q" placeholder="搜尋"></tc-search-bar>
```

### React

```tsx
import { TcSearchBar } from '@tzuchi/react';

<TcSearchBar
  placeholder="搜尋"
  onTcSearch={(e) => runSearch(e.detail.value, e.detail.category)}
/>;
```

### 含分類選擇器

加上 `with-category` 會在前端顯示分類選擇器，選項以 `categories`（物件陣列 property 或 JSON 字串屬性）提供。切換分類會發出 `tc-category-change`：

<Demo>
  <tc-search-bar
    with-category
    category="book"
    categories='[{"value":"all","label":"全部"},{"value":"book","label":"跨書搜尋"},{"value":"article","label":"文章"}]'
  ></tc-search-bar>
</Demo>

### 事件

- 輸入時發出 `tc-input`，`detail: { value }`。
- 按下 `Enter` 或點擊搜尋鈕發出 `tc-search`，`detail: { value, category }`。
- 切換分類發出 `tc-category-change`，`detail: { category }`。

所有事件皆 `composed` 且 `bubbles`。

### 無障礙（Accessibility）

- 外框為 `<form role="search">`，組成自己的送出流程（非 form-associated）。
- 文字輸入框以 `aria-label`（預設取 `placeholder`）提供無障礙名稱。
- 搜尋鈕 `aria-label="搜尋"`，分類選擇器 `aria-label="搜尋分類"`。
- `:focus-within` 焦點環使用 `border.focus` 與柔光環，內部控制項 `:focus-visible` 使用 `--tc-focus-ring-*` token。
- `disabled` 會停用內部所有原生控制項（非 `pointer-events:none`）。
