## 用法

導覽列放在每一頁的最上方，讓讀者知道自己在哪個網站，並且能前往網站的幾個主要區域。左邊放網站名稱或標誌，中間放主要選單，右邊放搜尋、語言等操作；畫面寬度小於 768px（手機、直向的平板）時，主要選單會收進「選單」按鈕。元件另有一個品牌底色（brand）變體，但目前在網站上看起來和預設一樣（待工程修正），請先用預設。如果只是在同一頁的幾組內容之間切換，請改用「頁籤」；電子書的閱讀畫面請改用「電子書工具列」。

## 組成

| 部位     | 說明                                                                                                           |
| -------- | -------------------------------------------------------------------------------------------------------------- |
| 容器     | 整條導覽列的底色、高度和下方的分隔線。底色和文字色跟著主題和色彩模式變。                                   |
| 品牌區   | 可省略。左邊的網站名稱或標誌，讓讀者知道自己在哪個網站。                                                       |
| 主要選單 | 中間的幾個主要連結，通常用「連結」元件。寬畫面排成一列；窄畫面收進抽屜。螢幕閱讀器會把這一區唸成「主要導覽」。 |
| 操作區   | 可省略。右邊的搜尋、語言、登入等小按鈕，通常用「圖示按鈕」。窄畫面上也一直看得到，不會收進抽屜。               |
| 選單按鈕 | 只在窄畫面出現的三條線按鈕，按下打開抽屜，圖示變成叉叉，再按一次關閉。                                         |
| 抽屜     | 窄畫面上，主要選單改成一列一個連結，從導覽列下方展開。按 Esc 鍵或點導覽列外面也會關閉。                        |
| 焦點框   | 用鍵盤選到選單按鈕時出現的外框，讓不用滑鼠的人知道目前在哪裡。顏色跟著主題。                               |

## 給工程師

以下是給工程師的安裝與 API 說明，美編（設計）、網站的編輯和致遠（廠商）可以略過。

<StorybookNote tag="tc-navbar" />

`<tc-navbar>` 是響應式的網站頂部列／站台 header：`brand` 插槽放標誌或站名（inline-start），預設插槽放主要導覽項目（桌機水平排列），`actions` 插槽放搜尋／語言／登入等操作（inline-end）。於平板斷點（`--tc-breakpoint-tablet` = 768px）以下，導覽會收合為漢堡選單，點擊後以垂直抽屜呈現。下方為**可互動的真實元件**：

### 變體（variant）

`brand` 變體以品牌深藍底搭配 on-brand 文字；`light`（預設）為白底搭配預設文字色。

<Demo>
  <tc-navbar variant="brand">
    <strong slot="brand">慈濟基金會</strong>
    <tc-link href="#news">全球消息</tc-link>
    <tc-link href="#events">活動訊息</tc-link>
    <tc-icon-button slot="actions" label="搜尋">
      <tc-icon name="search"></tc-icon>
    </tc-icon-button>
  </tc-navbar>
</Demo>

### 黏附（sticky）

設定 `sticky` 後，導覽列以 `position: sticky; top: 0` 黏附於捲動容器頂部，`z-index` 採用 `--tc-z-sticky`。

```html
<tc-navbar sticky>
  <strong slot="brand">慈濟</strong>
  <tc-link href="#news">全球消息</tc-link>
</tc-navbar>
```

### 行動抽屜（open）

768px 以下會出現漢堡按鈕；點擊切換 `open` 屬性並發出 `tc-menu-toggle`。導覽改以垂直抽屜呈現於列下方。按 `Escape` 或點擊列外區域皆會關閉抽屜。

```html
<tc-navbar open>
  <strong slot="brand">慈濟</strong>
  <tc-link href="#news">全球消息</tc-link>
  <tc-link href="#events">活動訊息</tc-link>
</tc-navbar>
```

```js
navbar.addEventListener('tc-menu-toggle', (e) => {
  console.log('drawer open?', e.detail.open);
});
```

### 無障礙（Accessibility）

- 外層為原生 `<header>` 並帶 `role="banner"`。
- 導覽區為原生 `<nav>` 並帶 `aria-label="主要導覽"`。
- 漢堡按鈕帶 `aria-label="選單"`、`aria-controls`（指向 nav）與 `aria-expanded`（隨 `open` 同步）。
- `Escape` 與點擊列外區域皆會關閉抽屜。
- 焦點環使用 `--tc-focus-ring-*` token。
