## 用法

電子書工具列放在電子書閱讀畫面的最上方：左邊是返回鍵，中間是書名，右邊是閱讀時用的工具，例如搜尋、書籤、語音朗讀。整列是一個圓角的長條。畫面寬度小於 768px 時，書名從置中改成靠左、貼著返回鍵；右邊的工具按鈕不會收起來。它只用在電子書的閱讀畫面，一般網頁的最上方請用「導覽列」。元件另有一個品牌底色（brand）變體，但目前在網站上看起來和預設一樣（待工程修正），請先用預設。

## 組成

| 部位   | 說明                                                                                           |
| ------ | ---------------------------------------------------------------------------------------------- |
| 容器   | 圓角長條，有淡淡的底色和外框。底色和文字色跟著網站主題和色彩模式變。                           |
| 返回鍵 | 內建在最左邊的箭頭按鈕，讓讀者離開閱讀畫面。螢幕閱讀器預設唸作「返回」，可以改成更清楚的說法。 |
| 書名   | 可省略。寬畫面置中，窄畫面靠左。只排一行，太長時從後面截斷，顯示「…」（上方第二個預覽）。      |
| 工具列 | 右邊的一排工具按鈕，通常用「圖示按鈕」，由網站決定放哪幾個。                                   |
| 焦點框 | 用鍵盤選到返回鍵或工具按鈕時出現的外框，讓不用滑鼠的人知道目前在哪裡。顏色跟著網站主題。       |

### 書名（book-title 與 title 插槽）

以 `book-title` 屬性設定置中書名；若需自訂排版，可改用 `title` 插槽覆寫（插槽優先）。過長的書名會以省略號截斷，避免擠壓工具列。

### 無障礙（Accessibility）

- host 取得 `role="toolbar"` 與 `aria-label`（電子書工具列）。
- 返回鍵為原生 `<button>`，其 `aria-label` 由 `back-label` 控制（預設 `返回`），點擊派發 `tc-back`（composed、bubbles）。
- 尾端工具控制項由使用者提供，建議使用 `<tc-icon-button>` 並各自設定 `label`。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
