## 用法

色彩模式切換讓讀者在淺色和深色之間切換整個網站。讀者第一次來時，網站先跟著他裝置的設定；按過一次之後，網站會記住他的選擇，下次再來也一樣。它只切換淺色和深色，不切換網站主題：網站主題是這個網站本身的外觀，讀者不能換。一般用只有圖示的樣式放在頁首；空間夠、或擔心讀者看不懂圖示時，用加上文字的樣式。

## 組成

| 部位     | 說明                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| 按鈕     | 圓形的外框按鈕，大小用的是控制項的標準尺寸，用手指也好按。滑鼠移上去時換成淡淡的品牌底色和主色外框。                           |
| 圖示     | 顯示「按下去會換成什麼」：淺色時是月亮（換成深色），深色時是太陽（換成淺色）。                                 |
| 文字     | 可省略。打開時在圖示旁顯示「切換至深色模式」或「切換至淺色模式」，文字是固定的，不能改。                       |
| 焦點框   | 用鍵盤選到它時出現的外框，讓不用滑鼠的人知道目前在哪裡。                                                     |

不論有沒有顯示文字，螢幕閱讀器都會唸出「切換至深色模式」或「切換至淺色模式」。

## 給工程師

以下是給工程師的安裝與 API 說明，美編（設計）、網站的編輯和廠商可以略過。

<StorybookNote tag="tc-theme-toggle" />

`<tc-theme-toggle>` 切換 `<html>` 的 `data-theme` 屬性。深色色票由 `@tzuchi/tokens` 的
`[data-theme="dark"]` 區塊提供，元件僅引用語意色 token，因此整個元件庫會透過 CSS 變數
串接**自動換色**——切換鈕本身不需要知道任何元件的存在。

### 行為

- **記憶**：使用者點擊後寫入 `localStorage["tc-theme"]`；下次載入沿用。
- **系統跟隨**：在使用者尚未選擇前，跟隨系統 `prefers-color-scheme`，並即時回應系統切換。
- **同步外部變更**：以 `MutationObserver` 監看 `<html data-theme>`，與頁面上其他切換鈕
  （或 docs 內建切換）保持一致。
- **無障礙**：以 `role="switch"` + `aria-checked` 呈現，並提供動態 `aria-label`
  （「切換至深色／淺色模式」）。

### 防止閃爍（anti-FOUC）

元件在 `connectedCallback` 才套用色彩模式，無法避免整頁載入時的閃爍。請在 `<head>`
**最前面**加入一段同步 inline script，在首次繪製前就設定好 `data-theme`：

```html
<script>
  (function () {
    try {
      var s = localStorage.getItem('tc-theme');
      var t =
        s === 'light' || s === 'dark'
          ? s
          : matchMedia('(prefers-color-scheme: dark)').matches
            ? 'dark'
            : 'light';
      document.documentElement.setAttribute('data-theme', t);
    } catch (e) {}
  })();
</script>
```
