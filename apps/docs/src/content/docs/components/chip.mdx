## 用法

膠囊標籤是一顆顆圓角的小標籤，讓讀者點選來篩選內容，例如只看「慈善」類的文章；點一下選取，再點一下取消，好幾顆可以同時選取。加上尾端的 × 時，也可以用來列出讀者已經選好、可以一個個拿掉的條件。如果只是標示分類或狀態、讀者不需要點，請改用「徽章」；一次只能選一個時，請改用「單選鈕」；送出、報名這類動作請用「按鈕」。

## 組成

| 部位     | 說明                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 容器     | 膠囊形，用淡淡的品牌底色。選取時底色加深，並多一圈主色外框。                             |
| 文字     | 必填。短短幾個字，例如「慈善」。標籤不會換行，字越多標籤就越長。                         |
| 前置圖示 | 可省略。放在文字前面的小圖示，用來補充文字。                                             |
| 移除鈕   | 可省略。尾端的 ×，按下去表示要拿掉這個標籤；螢幕閱讀器會唸「移除」。                     |
| 焦點框   | 用鍵盤選到標籤時出現的外框，讓不用滑鼠的人知道目前在哪裡。                               |
| 停用狀態 | 整顆變淡，不能點、不能選取，也不能移除。                                                 |

以下是給工程師的安裝與 API 說明，美編（設計）、網站的編輯和致遠（廠商）可以略過。

<StorybookNote tag="tc-chip" />

`<tc-chip>` 是膠囊形的 tonal 標籤，採用品牌淺底（brand surface）配品牌主色文字（brand primary）。可作為動作型（assist）或篩選型（filter）標籤，支援前置圖示、可切換選取與可移除。下方為**可互動的真實元件**：

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-chip>連結</tc-chip>
<tc-chip removable>增加</tc-chip>
```

### React

```tsx
import { TcChip } from '@tzuchi/react';

<TcChip removable onTcRemove={() => removeTag(id)}>
  增加
</TcChip>;
```

### 可移除

`removable` 會在尾端顯示關閉鈕。點擊關閉鈕或於膠囊標籤上按 `Delete` / `Backspace` 會發出 `tc-remove`，且**不會**切換選取狀態：

<Demo>
  <tc-chip
    removable
    ontc-remove="this.remove();"
  >按我移除</tc-chip>
</Demo>

### 無障礙（Accessibility）

- 膠囊標籤本體為 `role="button"`，可切換 `selected` 時以 `aria-pressed` 反映狀態。
- 鍵盤：`Enter` / `Space` 切換選取；`removable` 時 `Delete` / `Backspace` 發出 `tc-remove`。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
- `disabled` 以 `aria-disabled` 標示並移出 Tab 順序（非 `pointer-events:none`）。
