## 用法

下拉選單讓讀者從一串選項裡選一個，例如地區、場次。平常只佔一行，點開後才在下方列出所有選項，選好後選單自動收起，框裡顯示選到的那一項。適合選項比較多、版面放不下的時候；如果只有少少幾個選項、希望讀者一眼看到全部，請改用「單選鈕」。需要讀者自己打字的，請用「輸入框」。

## 組成

| 部位     | 說明                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------- |
| 選單框   | 有框線的一格，顯示提示文字或已選的選項，右邊有向下的箭頭。點開時框的底色變深、箭頭轉向上。     |
| 提示文字 | 還沒選的時候顯示的淡色文字，例如「請選擇地區」。選好後換成主色的選項名稱。                     |
| 選項清單 | 點開後在選單框下方出現，底色是淡淡的品牌色；目前選到的那一項底色比較深。                       |
| 焦點框   | 用鍵盤選到選單時出現的外框。用鍵盤的方向鍵就能上下選擇、按 Enter 選定、按 Esc 關閉。           |
| 停用狀態 | 整格變淡，點了不會展開。                                                                       |

## 給工程師

以下是給工程師的安裝與 API 說明，美編（設計）、網站的編輯和廠商可以略過。

`<tc-dropdown>` 是單選的 outlined 下拉選單（combobox / listbox）。選項可由 `options` property（物件陣列）或 `options` 屬性（JSON 字串）提供，因此純 HTML 與 React 皆可使用。下方為**可互動的真實元件**：

<Demo>
  <tc-dropdown

    options='[{"value":"tw","label":"台灣"},{"value":"jp","label":"日本"},{"value":"us","label":"美國"}]'
    style="width:180px;"
  ></tc-dropdown>
  <tc-dropdown
    placeholder="請選擇地區"
    value="jp"

  <tc-dropdown
    placeholder="已停用"

    style="width:180px;"
  ></tc-dropdown>
</Demo>

### 純 HTML

選項以 JSON 字串放入 `options` 屬性：

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-dropdown
  name="region"
  placeholder="請選擇地區"
  options='[{"value":"tw","label":"台灣"},{"value":"jp","label":"日本"}]'
></tc-dropdown>
```

### React

選項以物件陣列 property 傳入：

```tsx
import { TcDropdown } from '@tzuchi/react';

<TcDropdown
  name="region"
  placeholder="請選擇地區"
  options={[
    { value: 'tw', label: '台灣' },
    { value: 'jp', label: '日本' },
  ]}
  onTcChange={(e) => console.log(e.detail.value)}
/>;
```

### 事件

- `tc-change`：選取值改變時觸發，`detail: { value }`（composed、bubbles）。

### 鍵盤操作

- `Enter` / `空白鍵` / `↓`：展開選單。
- `↓` / `↑`：在選單中移動作用中選項。
- `Home` / `End`：跳到第一個 / 最後一個選項。
- `Enter`：選取作用中選項。
- `Esc`：關閉選單並將焦點移回觸發按鈕。
- 點選選單外或按 `Esc` 皆會關閉選單。

### 表單

`<tc-dropdown>` 透過 Form-Associated Custom Elements（ElementInternals）參與表單：`name` / `value` 會被序列化到 `FormData`。

### 無障礙（Accessibility）

- 觸發按鈕為原生 `<button>`，標註 `role=combobox`、`aria-haspopup=listbox`、`aria-expanded`、`aria-controls`。
- 選單為 `role=listbox`，選項為 `role=option` 並以 `aria-selected` 標示目前選取項。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
- `disabled` 透過停用內部原生按鈕實作（非 `pointer-events:none`）。
