## 用法

圖示按鈕是只有一個圖示、沒有文字的圓形按鈕，用在大家一看就懂的動作，例如返回、展開、搜尋、開啟選單，常放在導覽列、工具列這類空間很小的地方。淡底（tonal）是一般用法，實心（filled）用來強調；有 48px 和 64px 兩種大小。如果動作需要用文字才說得清楚，或是畫面上最重要的動作（例如送出、捐款），請改用有文字的「按鈕」。

## 組成

| 部位       | 說明                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------- |
| 圓形容器   | 按鈕的底色。淡底按鈕用淡淡的品牌底色，實心按鈕用主色；大小有 48px 和 64px 兩種。                   |
| 圖示       | 必填。放在圓形中間的一個圖示，顏色跟著變體：淡底按鈕是主色圖示，實心按鈕的圖示用和主色對比清楚的顏色。 |
| 標籤       | 必填，但畫面上看不到。用一句話說出按下去會做什麼，例如「返回上一頁」；螢幕閱讀器會唸這段文字。     |
| 焦點框     | 用鍵盤選到按鈕時出現的外框，讓不用滑鼠的人知道目前在哪裡。                                         |
| 停用狀態   | 暫時不能按時整顆變淡。                                                                             |

```tsx
<TcIconButton variant="filled" size="lg" label="向下展開" onClick={handleExpand}>
  <TcIcon name="arrow-down" />

```

### 變體與尺寸

- `variant="tonal"`（預設）：品牌淺色底 + 品牌主色圖示。
- `variant="filled"`：品牌主色底 + 對比文字色圖示。
- `size="md"`（預設，48px）/ `size="lg"`（64px），對應 `--tc-size-control-*`。

### 無障礙（Accessibility）

- `label` 為必填，會套用至內部原生 `<button>` 的 `aria-label`，供螢幕報讀器辨識。
- 內含原生 `<button>`，支援鍵盤 Enter / Space。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
- `disabled` 透過停用內部的原生控制項實作（非 `pointer-events:none`）。
