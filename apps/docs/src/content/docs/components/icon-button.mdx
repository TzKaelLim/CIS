## 用法

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-icon-button variant="tonal" label="返回">
  <tc-icon name="arrow-left"></tc-icon>
</tc-icon-button>
```

### React

```tsx
import { TcIconButton } from '@tzuchi/react';

<TcIconButton variant="filled" size="lg" label="向下展開" onClick={handleExpand}>
  <TcIcon name="arrow-down" />
</TcIconButton>;
```

## 變體與尺寸

- `variant="tonal"`（預設）：品牌淺色底 + 品牌主色圖示。
- `variant="filled"`：品牌主色底 + 對比文字色圖示。
- `size="md"`（預設，48px）/ `size="lg"`（64px），對應 `--tc-size-control-*`。

## 無障礙（Accessibility）

- `label` 為必填，會套用至內部原生 `<button>` 的 `aria-label`，供螢幕報讀器辨識。
- 內含原生 `<button>`，支援鍵盤 Enter / Space。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
- `disabled` 透過停用內部原生控件實作（非 `pointer-events:none`）。
