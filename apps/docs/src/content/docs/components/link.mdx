## 用法

連結帶讀者前往另一個頁面或網站，常放在一段文字中間，或一整排列在頁尾、選單裡。預設連結是品牌色的粗體字，讀者一眼就看得出可以點；隱性連結（subtle）平常是內文的顏色，滑過時才變色，適合放在頁尾這類一整排都是連結、讀者本來就知道可以點的地方。如果是送出、報名這類「做一件事」的動作，請改用「按鈕」。

## 組成

| 部位     | 說明                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------- |
| 連結文字 | 必填。寫出點下去會到哪裡，例如「查看活動行事曆」。字型大小跟著周圍的文字，所以可以直接放在段落裡。 |
| 顏色     | 預設連結是品牌色粗體，隱性連結是內文的顏色。滑鼠移上去時變色並出現底線。                           |
| 焦點框   | 用鍵盤選到連結時出現的外框，讓不用滑鼠的人知道目前在哪裡。                                         |
| 停用狀態 | 變成淡灰色、點了不會換頁；螢幕閱讀器仍然唸得到這段文字。                                           |

### 行內使用

`tc-link` 為 `display: inline`，可直接置於段落文字之中：

<Demo>
  <p style="max-width:32rem;">
    慈濟基金會在全球推動慈善志業，歡迎您
    <tc-link href="#">詳細了解我們所做的</tc-link>
    ，一起成就善的循環。
  </p>
</Demo>

### 無障礙（Accessibility）

- 內含原生 `<a>`，支援鍵盤 Enter 與螢幕閱讀器的連結語意。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
- `disabled` 時改以 `<span aria-disabled="true">` 呈現，無法點擊或導覽（非 `pointer-events:none`，AT 仍可讀取）。
- `target="_blank"` 會自動補上 `rel="noopener noreferrer"`，可由 `rel` 屬性覆寫。
