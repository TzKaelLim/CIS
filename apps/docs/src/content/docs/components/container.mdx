## 用法

版心容器決定一段內容最寬可以到多寬，並把內容放在畫面中間，左右再留一點空白，讀者在大螢幕上不用左右轉頭讀很長的一行字。它本身看不見，上面的預覽用虛線框標出不同寬度的版心。整個網站的頁面區塊都用它包住主要內容，寬度才會一致；要把內容排成好幾欄，請在版心容器裡面再放「[格線](/components/grid/)」。

## 組成

| 部位     | 說明                                                                                                           |
| -------- | -------------------------------------------------------------------------------------------------------------- |
| 外層     | 佔滿它所在位置的整個寬度。滿版的底色可以放在這一層，底色會延伸到畫面兩邊，文字仍留在版心裡。                   |
| 版心     | 內容真正所在的區域，有最大寬度，預設放在中間。最大寬度有五種，從窄到寬是 sm、md、lg、xl（預設）和 full。       |
| 左右內距 | 版心兩邊的空白，手機最小，平板和桌機逐步加大，文字不會貼著螢幕邊緣。可以關掉，讓滿版圖片貼齊版心邊界。         |
| 內容     | 放進版心容器的任何東西：標題、文章、格線、卡片等。版心容器不改變它們的樣子。                                   |

每種寬度和內距的實際數值，見下方「給工程師」。

Storybook 是工程師逐一檢查元件各種狀態的工具網站，目前只有預設網站主題（慈濟入口網）的淺色和深色。它只在正式上線的手冊才開得了；在自己的電腦上預覽手冊時，按鈕會顯示找不到頁面（詳見[開始使用](/docs/#給工程師)）。

`<tc-container>` 是版心（layout）容器：將內容約束在最大寬度內、水平置中，並提供隨視窗增長的左右內距（gutter）。`size` 對應設計系統的斷點寬度（`--tc-container-sm/md/lg/xl/full`），分別為 375 / 768 / 1024 / 1280 / 1920px。下方為**可互動的真實元件**（虛線框示意版心邊界）：

### 尺寸（size）

`size` 設定最大寬度，對應 `--tc-container-*` 斷點寬度原語。`full` 對應 1920px 寬版（桌機全幅）。

### 內距（gutter）與置中（centered）

`gutter`（預設開啟）提供隨視窗增長的左右內距：行動裝置 `--tc-space-16`、平板（≥768px）`--tc-space-24`、桌機（≥1024px）`--tc-space-32`。`gutter` 是布林屬性——移除整個屬性即可關閉內距（例如讓全幅媒體貼齊邊緣）；以 JS 設定 `el.gutter = false` 亦可。`centered`（預設開啟）以 `margin-inline:auto` 水平置中。

> 注意：`gutter` 與 `centered` 為布林屬性，**屬性存在即為 true**（`gutter="false"` 仍為開啟）。需關閉時請移除屬性或以 property 設為 `false`。

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-container size="xl">
  <h1>頁面標題</h1>
  <p>版心內容會被約束在最大寬度內並水平置中。</p>
</tc-container>
```

### React

```tsx
import { TcContainer } from '@tzuchi/react';

<TcContainer size="lg">
  <h1>頁面標題</h1>
  <p>版心內容</p>
</TcContainer>;
```

### 自訂最大寬度

`size` 變體會設定內部的 `--tc-container-max`；若需自訂任意寬度，可直接覆寫此變數：

```html
<tc-container style="--tc-container-max: 960px">…</tc-container>
```

### 無障礙（Accessibility）

- `<tc-container>` 純為版面（layout）容器，不引入額外的語意角色；請在其內容中使用適當的地標（如 `<main>`、`<section>`）與標題結構。
- 內距與最大寬度皆使用設計 token（`--tc-container-*`、`--tc-space-*`），確保跨頁面一致的版心與留白。
