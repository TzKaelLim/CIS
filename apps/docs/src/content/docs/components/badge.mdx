## 用法

徽章是貼在旁邊的小標記，用來標示分類、狀態或數量，例如「兒少」「已上線」「12」。它只給人看，不能點。要讓讀者點選、篩選或移除的小標籤，請改用「膠囊標籤」；要讓讀者按下去做一件事，用「按鈕」。徽章有六種色調：一般（neutral）和品牌（brand）用在分類，成功（success）、錯誤（error）、警告（warning）、資訊（info）用在狀態；外觀有淡底（soft）、實底（filled）、外框（outline）三種，另有小尺寸（sm）給平板直式和手機用。

## 組成

| 部位             | 說明                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| 底色與外框       | 依外觀而定：淡底配色調文字、實底配反白文字，或透明底配色調外框。顏色跟著主題。                           |
| 文字             | 必填。分類、狀態或數字，排成一行，不會換行。                                                                 |
| 狀態圓點         | 可省略。文字前面的小圓點，只是裝飾，螢幕閱讀器不會唸。                                                       |
| 形狀             | 預設是小圓角；也可以改成兩端全圓的膠囊形，適合放數字。                                                       |
| 給螢幕閱讀器的字 | 只有狀態色調才有：看不見的「成功：」「錯誤：」「警告：」「資訊：」，螢幕閱讀器會先唸這幾個字，再唸徽章文字。 |

### 色調（Tone）

色調對應語意色彩。`neutral` 與 `brand` 視為一般標籤；`success`、`error`、`warning`、`info` 視為狀態，會附帶一段視覺隱藏文字供螢幕報讀器辨識。

<Demo>

  <tc-badge tone="brand">brand</tc-badge>
  <tc-badge tone="success">success</tc-badge>
  <tc-badge tone="error">error</tc-badge>
  <tc-badge tone="warning">warning</tc-badge>
  <tc-badge tone="info">info</tc-badge>
</Demo>

### 變體（Variant）

`soft`（預設）為淡底配色調文字；`filled` 為實底配反白文字；`outline` 為透明底配色調邊框與文字。

<Demo>
  <tc-badge tone="brand" variant="soft">soft</tc-badge>
  <tc-badge tone="brand" variant="filled">filled</tc-badge>
  <tc-badge tone="brand" variant="outline">outline</tc-badge>
</Demo>

### 尺寸（Size）

`md`（預設）適用桌機與平板橫式；`sm` 適用平板直式與手機。

### 無障礙（Accessibility）

- 徽章預設為 `role="presentation"`（純裝飾）。若徽章承載狀態語意，作者可自行加上 `role="status"`。
- 狀態色調（`success` / `error` / `warning` / `info`）會附帶視覺隱藏文字，向螢幕報讀器說明狀態。
- 狀態圓點為純裝飾（`aria-hidden`），不依賴顏色傳達意義——色調搭配文字與隱藏標籤共同表意。
- 徽章為非互動元件，不接收焦點、不發出事件。
