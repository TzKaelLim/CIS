## 用法

按鈕讓讀者做一件事，例如送出表單、確認報名、前往下一步。每個區塊裡最重要的動作用實心按鈕，其他動作用外框或淡底按鈕，讀者一眼就知道該先按哪一個；如果只是帶讀者去讀另一頁的內容，請改用「連結」。

## 組成

| 部位     | 說明                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 容器     | 按鈕的底色和外框。實心按鈕用主色，外框按鈕只有邊框，淡底按鈕用淡淡的品牌底色。           |
| 文字     | 必填。寫出按下去會發生什麼，例如「送出」「立即捐款」。螢幕閱讀器也會唸這段文字。         |
| 前後圖示 | 可省略。放在文字前面或後面的小圖示，用來補充文字，不能取代文字。                         |
| 焦點框   | 用鍵盤選到按鈕時出現的外框，讓不用滑鼠的人知道目前在哪裡。顏色跟著網站主題。             |
| 停用狀態 | 暫時不能按時變淡。最好在旁邊寫出為什麼不能按，以及怎麼樣才能按。                         |

## 給工程師

以下是給工程師的安裝與 API 說明，美編（設計）、網站的編輯和致遠（廠商）可以略過。

<StorybookNote tag="tc-button" />

`<tc-button>` 是主要按鈕，提供三種變體與 form-associated 表單送出。頁面最上方的大預覽就是**可互動的真實元件**。

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-button variant="filled">送出</tc-button>
```

### React

```tsx
import { TcButton } from '@tzuchi/react';

<TcButton variant="filled" onClick={handleSubmit}>送出</TcButton>;
```

### 表單

`type="submit"` 時，`tc-button` 透過 Form-Associated Custom Elements（ElementInternals）送出所屬 `<form>`：

<Demo>
  <form
    onsubmit="event.preventDefault(); this.querySelector('output').textContent='✅ 已送出';"
    style="display:flex; gap:.75rem; align-items:center;"
  >
    <tc-button type="submit" variant="filled">送出表單</tc-button>
    <output></output>
  </form>
</Demo>

### 無障礙

- 內含原生 `<button>`，支援鍵盤 Enter / Space。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
- `disabled` 透過停用內部的原生控制項實作（非 `pointer-events:none`）。
