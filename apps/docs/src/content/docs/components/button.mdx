## 在各網站的樣子

:::caution[設計示範（prototype）]
這一段是設計示範：同一個按鈕在不同網站主題下的顏色。環保網的顏色是示意值，網站名稱與做法都還待核定。
:::

上方可以點的按鈕是真正的元件，用的是預設主題（入口網），會跟著手冊右上角的淺色／深色切換；下面的分頁則是固定配色的示意圖，用來比較不同網站。

元件只有一份，每個網站只換顏色。點上方分頁切換網站；每個分頁左邊是淺色、右邊是深色。你選的網站會被記住，下次打開這一頁時會直接顯示同一個網站。

## 用法

### 純 HTML

```html
<link rel="stylesheet" href="@tzuchi/tokens/tokens.css" />
<script type="module" src="@tzuchi/components/cdn"></script>

<tc-button variant="filled">送出</tc-button>
```

### React

```tsx
import { TcButton } from '@tzuchi/react';

<TcButton variant="filled" onClick={handleSubmit}>送出</TcButton>;
```

## 表單

`type="submit"` 時，`tc-button` 透過 Form-Associated Custom Elements（ElementInternals）提交所屬 `<form>`：

<Demo>
  <form
    onsubmit="event.preventDefault(); this.querySelector('output').textContent='✅ 已提交';"
    style="display:flex; gap:.75rem; align-items:center;"
  >
    <tc-button type="submit" variant="filled">提交表單</tc-button>
    <output></output>
  </form>
</Demo>

## 無障礙（Accessibility）

- 內含原生 `<button>`，支援鍵盤 Enter / Space。
- `:focus-visible` 焦點環使用 `--tc-focus-ring-*` token。
- `disabled` 透過停用內部原生控件實作（非 `pointer-events:none`）。
