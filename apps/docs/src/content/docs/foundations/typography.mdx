## 給工程師

以下是給工程師的技術說明，美編（設計）、網站的編輯和廠商可以略過。

字級以語意 token（`typography.*`）表達，每個用途是一個 DTCG `typography` composite，
編譯為單一 CSS `font` shorthand 變數（含 line-height）。上面每一行都以實際的
`var(--tc-typography-*)` 顯示。字型家族預設 `Noto Sans TC` 加系統的後備字型（fallback），可由 `--tc-font-family-base` 覆寫。
