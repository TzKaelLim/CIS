UIKit 內建**淺色（預設）**與**深色**兩種色彩模式。原則是：**只有語意色和陰影會換**。
基礎 Foundations 的色票（所有網站共用）不會變；元件只使用語意色和元件 token。所以深色模式只需要重新指定語意色和陰影，所有元件就會自動跟著變。

「色彩模式」和「網站主題」是兩回事：網站主題決定是哪一個網站（慈濟入口網、慈濟環保網…），色彩模式決定淺色或深色，兩者可以自由組合。詳見[網站主題總覽](/themes/)。

## 運作原理：三層怎麼接起來

這裡的三層是：基礎 Foundations → 語意色 → 元件 token。網站主題和色彩模式改的都是中間那一層（語意色）。

以實心按鈕為例：按鈕的底色是元件 token `button.filled.bg`，它指向語意色 `color.brand.primary`（品牌主色）；品牌主色在淺色模式指向基礎色 `color.blue.900`，在深色模式改指向較亮的 `color.blue.300`。按鈕本身完全不用改，深色模式只換了中間那一層的指向。

## 給工程師

以下是給工程師的啟用方式和設計決策，美編（設計）、網站的編輯和致遠（廠商）可以略過。

### 啟用方式

深色色票包在兩個選擇器（selector）內，由 `@tzuchi/tokens/tokens.css` 一併提供：

```css
:root { /* 淺色：primitives + 語意 + 元件 */ }

[data-theme='dark'] { /* 語意色和陰影的覆寫 */ }

@media (prefers-color-scheme: dark) {
  :root:not([data-theme='light']) { /* 系統自動，除非明確選擇淺色 */ }
}
```

- **手動**：在 `<html>` 設定 `data-theme="dark"` 或 `"light"`。
- **系統自動**：未設定 `data-theme` 時，跟隨作業系統 `prefers-color-scheme`。
- **元件**：用 [`<tc-theme-toggle>`](/components/theme-toggle/) 切換並記憶選擇。

三層在 CSS 裡是 `var()` 串接，Shadow DOM 裡面也一樣：

```text
--tc-button-filled-bg     →  var(--tc-color-brand-primary)
--tc-color-brand-primary  →  var(--tc-color-blue-300)   (僅深色區塊覆寫此行)
```

### 關鍵設計決策

- **品牌色反轉（Material-3 tonal）**：深色模式的 `color.brand.primary` 由深靛藍 `color.blue.900` 改指向較亮的 `color.blue.300`，在深色面上才讀得清楚。連帶地 `color.text.on-brand` 由白色翻轉為深靛藍（白字在淺藍底對比不足），因此實心按鈕在深色模式是「淺藍底＋深藍字」。
- **表面分層**：深色模式的 `color.surface.subtle` 比 `color.surface.default` 更深，讓卡片以色階浮起，不全靠陰影。
- **陰影加強**：深色模式 `--tc-elevation-*` 提高黑色不透明度（純黑陰影在深色面上幾乎不可見）。
- **回饋色提亮**：`color.feedback.error`／`color.feedback.success` 在深色改用較亮的基礎色，作為深色面上的前景文字仍達 AA。

### 擴充：新增元件時

引用語意色（`--tc-color-surface-default`、`--tc-color-text-default`、`--tc-color-brand-primary`…）
而非 primitive 或寫死色碼，元件即自動支援深色。**勿**將 `color-mix(... , white)` 寫死白色作為底色，
請改用 `var(--tc-color-surface-default)`，使色調隨色彩模式調整。
